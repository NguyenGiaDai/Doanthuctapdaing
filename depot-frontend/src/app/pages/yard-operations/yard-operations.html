YARD OPERATIONS

Vận hành nhập / xuất container

Quản lý các nghiệp vụ vận hành bãi: nhập container vào bãi, xuất container theo lệnh giao, di dời vị trí và theo dõi lịch sử giao dịch.

Trạng thái UI nghiệp vụ

Bước này dựng giao diện, bước sau nối API thật.

IMPORT CONTAINER

Nhập container vào bãi

In
Luồng nghiệp vụ: kiểm tra container, kiểm tra vị trí trống, tạo giao dịch In, ghi nhận ContainerPosition, cập nhật trạng thái container thành InYard.

EXPORT CONTAINER

Xuất container khỏi bãi

Out
Luồng nghiệp vụ: xuất container phải có Delivery Order hợp lệ, còn hạn, đúng hãng khai thác, đúng loại container và container phải đang ở trong bãi.

MOVE CONTAINER

Di dời container trong bãi

Move
Luồng nghiệp vụ: di dời container tận dụng cập nhật ContainerPosition hiện tại. Khi nối API thật cần kiểm tra vị trí mới không bị trùng.
